## Objectifs
- Déterminer le signe d’un produit de nombres relatifs et le calculer.
- Calculer le quotient de deux nombres relatifs.
- Donner une valeur approchée d’un quotient.
- Enchaîner des calculs en respectant les priorités.

## Prérequis
- Addition et soustraction des nombres relatifs.
- Multiplication et division des nombres décimaux.

# I. Produit de deux nombres relatifs

:::exemple Observation
Extrait de la table de multiplication par $(-4)$ :
| $\times$ | $3$ | $2$ | $1$ | $0$ | $-1$ | $-2$ | $-3$ |
|---|---|---|---|---|---|---|---|
| $-4$ | $-12$ | $-8$ | $-4$ | $0$ | $4$ | $8$ | $12$ |

Chaque fois que le second facteur diminue de $1$, le produit augmente de $4$ : le produit de deux nombres négatifs est positif.
:::

:::regle
Pour multiplier deux nombres relatifs, on **multiplie leurs distances à zéro** et on détermine le signe :
- le produit de deux nombres de **même signe** est **positif** ;
- le produit de deux nombres de **signes contraires** est **négatif**.
:::

:::exemple
$(+3)\times(+5)=+15$ ; $(-4)\times(-2{,}5)=+10$ ; $(-6)\times(+7)=-42$ ; $(+0{,}5)\times(-8)=-4$.
:::

:::remarque
- $a\times0=0$ ; $a\times1=a$ ; $a\times(-1)=-a$ (l’opposé de $a$).
- La multiplication est commutative et associative.
:::

# II. Produit de plusieurs nombres relatifs

:::regle
Un produit de nombres relatifs non nuls est :
- **positif** s’il comporte un nombre **pair** de facteurs négatifs ;
- **négatif** s’il comporte un nombre **impair** de facteurs négatifs.
:::

:::exemple
- $(-2)\times(+3)\times(-5)$ : deux facteurs négatifs, le produit est positif : $+30$.
- $(-1)\times(-2)\times(-3)\times(+4)$ : trois facteurs négatifs, le produit est négatif : $-24$.
:::

:::methode Calculer astucieusement
$(-25)\times(-7{,}3)\times(-4)$ : trois facteurs négatifs, signe $-$ ; puis $25\times4=100$, donc le produit vaut $-730$.
:::

# III. Quotient de deux nombres relatifs

:::regle
Pour diviser deux nombres relatifs ($b\ne0$), on **divise leurs distances à zéro** et on applique la **même règle des signes** que pour le produit :
- même signe : quotient positif ;
- signes contraires : quotient négatif.
:::

:::exemple
$\dfrac{-12}{-4}=3$ ; $\dfrac{15}{-3}=-5$ ; $(-7)\div2=-3{,}5$ ; $\dfrac{-1{,}8}{0{,}6}=-3$.
:::

:::remarque
$\dfrac{-a}{b}=\dfrac{a}{-b}=-\dfrac ab$ et $\dfrac{-a}{-b}=\dfrac ab$.
:::

:::methode Valeur approchée d’un quotient
$\dfrac{-10}{3}=-3{,}333\ldots$
- Valeur approchée au dixième **par défaut** : $-3{,}4$ (le nombre inférieur le plus proche).
- Valeur approchée au dixième **par excès** : $-3{,}3$.
:::

# IV. Enchaînement de calculs

:::regle
Les priorités restent les mêmes : parenthèses, puis multiplications et divisions, puis additions et soustractions.
:::

:::exemple
$$A=-3+(-4)\times5=-3+(-20)=-23$$
$$B=(-2-6)\div(-4)+3\times(-1)=(-8)\div(-4)-3=2-3=-1.$$
:::

# Exercices

:::exercice Signe d’un produit
Sans calculer, donner le signe de : $(-3)\times(+8)$ ; $(-1{,}5)\times(-2)$ ; $(-1)\times(-2)\times(-3)$ ; $(-4)\times(+5)\times(-6)\times(-1)$.
:::

:::exercice Produits
Calculer : $(-7)\times(+6)$ ; $(-0{,}4)\times(-25)$ ; $(+12)\times(-0{,}5)$ ; $(-2)\times(-5)\times(-9)$ ; $(-0{,}25)\times(+13)\times(-4)$.
:::

:::exercice Quotients
1. Calculer : $\dfrac{-36}{9}$ ; $\dfrac{-48}{-6}$ ; $\dfrac{4{,}2}{-0{,}7}$ ; $(-27)\div(-0{,}3)$.
2. Donner une valeur approchée au dixième par défaut et par excès de $\dfrac{-5}{6}$.
:::

:::exercice Priorités
Calculer : $C=5-3\times(-4)$ ; $D=(-6)\times(-2)-15\div(-3)$ ; $E=\dfrac{-8+2}{-3}$ ; $F=(-1)\times\left[4-(-2)\times3\right]$.
:::

:::exercice Compléter
Compléter : $(-7)\times\ldots=21$ ; $\ldots\times(-0{,}5)=-4$ ; $\ldots\div(-3)=6$ ; $(-45)\div\ldots=9$.
:::

:::exercice Approfondissement — signe sans calcul
Sans calculer, donner le signe de :
1. $A=(-1)\times(-2)\times(-3)\times\cdots\times(-10)$ ;
2. $B=(-2{,}5)\times(+4)\times(-0{,}1)\times(-8)\times(-3)$ ;
3. $C=\dfrac{(-6)\times(-7)}{(-3)\times2}$.
Puis calculer $B$ et $C$.
:::

:::exercice Approfondissement — trouver les nombres
1. Le produit de deux nombres relatifs est $-36$ et leur somme est $0$. Quels sont ces nombres ?
2. Le produit de deux nombres entiers relatifs est $12$ et leur somme est $-7$. Quels sont-ils ?
:::

# Corrigés

:::corrige
Négatif ; positif ; négatif (trois facteurs négatifs) ; négatif (trois facteurs négatifs : $-4$, $-6$ et $-1$).
:::

:::corrige
$-42$ ; $+10$ ; $-6$ ; $-90$ ; $+13$.
:::

:::corrige
1. $-4$ ; $8$ ; $-6$ ; $90$.
2. $\dfrac{-5}6=-0{,}833\ldots$ : par défaut $-0{,}9$ ; par excès $-0{,}8$.
:::

:::corrige
- $C=5-(-12)=17$.
- $D=12-(-5)=17$.
- $E=\dfrac{-6}{-3}=2$.
- $F=(-1)\times(4+6)=-10$.
:::

:::corrige
$(-7)\times(-3)=21$ ; $8\times(-0{,}5)=-4$ ; $(-18)\div(-3)=6$ ; $(-45)\div(-5)=9$.
:::

:::corrige
1. Dix facteurs négatifs (nombre pair) : $A$ est positif.
2. Quatre facteurs négatifs : $B$ est positif ; $B=2{,}5\times4\times0{,}1\times8\times3=24$.
3. Numérateur positif, dénominateur négatif : $C$ est négatif ; $C=\dfrac{42}{-6}=-7$.
:::

:::corrige
1. Somme nulle : les nombres sont opposés, $a\times(-a)=-36$, donc $a^2=36$ : $6$ et $-6$.
2. Produit positif et somme négative : les deux sont négatifs ; $-3$ et $-4$ (car $(-3)\times(-4)=12$ et $-3-4=-7$).
:::
