## Objectifs
- Connaître les propriétés de l’égalité.
- Reconnaître une équation, son inconnue et vérifier si un nombre est solution.
- Résoudre les équations du type $x+a=b$, $ax=b$ et $ax+b=c$.
- Mettre un problème en équation et le résoudre.

## Prérequis
- Calcul sur les nombres relatifs et fractionnaires.
- Réduction et développement d’expressions littérales.

# I. Égalités

:::propriete 1
On ne change pas une égalité en **ajoutant** (ou en **soustrayant**) un même nombre à ses deux membres :
$$\text{si }a=b,\ \text{alors }a+c=b+c\ \text{et}\ a-c=b-c.$$
:::

:::propriete 2
On ne change pas une égalité en **multipliant** (ou en **divisant**) ses deux membres par un même nombre **non nul** :
$$\text{si }a=b,\ \text{alors }a\times c=b\times c\ \text{et, pour }c\ne0,\ \frac ac=\frac bc.$$
:::

:::exemple
On a $13=13$, donc $13+5=13+5$ ; de $2x=10$ on déduit $\dfrac{2x}2=\dfrac{10}2$, soit $x=5$.
:::

# II. Équations

:::definition
Une **équation** est une égalité dans laquelle figure un nombre inconnu, désigné par une lettre, appelé **inconnue**. Une **solution** de l’équation est une valeur de l’inconnue pour laquelle l’égalité est vraie.
:::

:::exemple
Dans l’équation $3x-4=11$, l’inconnue est $x$.
- Pour $x=5$ : $3\times5-4=11$ ; l’égalité est vraie, $5$ est une solution.
- Pour $x=2$ : $3\times2-4=2\ne11$ ; $2$ n’est pas une solution.
:::

:::definition
**Résoudre** une équation, c’est trouver **toutes** ses solutions.
:::

# III. Résolution

:::methode Équation $x+a=b$
On soustrait $a$ aux deux membres : $x=b-a$.

$x+7=3\iff x=3-7\iff x=-4$.
:::

:::methode Équation $x-a=b$
On ajoute $a$ aux deux membres : $x=b+a$.

$x-2{,}5=6\iff x=8{,}5$.
:::

:::methode Équation $ax=b$ ($a\ne0$)
On divise les deux membres par $a$ : $x=\dfrac ba$.

$4x=18\iff x=\dfrac{18}4=\dfrac92$ ; $-3x=12\iff x=-4$ ; $\dfrac x5=2\iff x=10$.
:::

:::methode Équation $ax+b=c$
On isole d’abord le terme en $x$, puis on divise :
$$5x-3=17\iff5x=20\iff x=4.$$
:::

:::methode Inconnue dans les deux membres
On regroupe les termes en $x$ dans un membre et les nombres dans l’autre :
$$7x-2=3x+10\iff7x-3x=10+2\iff4x=12\iff x=3.$$
:::

:::remarque Vérification
On vérifie en remplaçant : $7\times3-2=19$ et $3\times3+10=19$. ✓
:::

:::exemple Avec des parenthèses
$$2(x+3)=x-1\iff2x+6=x-1\iff x=-7.$$
:::

# IV. Mise en équation d’un problème

:::methode Étapes
1. Lire et bien comprendre le problème.
2. Choisir l’inconnue.
3. Mettre le problème en équation.
4. Résoudre l’équation.
5. Interpréter le résultat et conclure.
6. Vérifier.
:::

:::exemple
Un cahier coûte $4$ DH de plus qu’un stylo. Trois cahiers et deux stylos coûtent $37$ DH. Quel est le prix de chaque article ?
- Soit $x$ le prix d’un stylo ; un cahier coûte $x+4$.
- $3(x+4)+2x=37\iff5x+12=37\iff5x=25\iff x=5$.
- Le stylo coûte $5$ DH et le cahier $9$ DH. Vérification : $3\times9+2\times5=37$. ✓
:::

# Exercices

:::exercice Vérifier une solution
1. Le nombre $3$ est-il solution de $4x-5=7$ ? de $2x+1=x+3$ ?
2. Le nombre $-2$ est-il solution de $x^2=4$ ? de $3x+8=x+4$ ?
:::

:::exercice Équations simples
Résoudre : $x+9=4$ ; $x-6=-2$ ; $7x=-35$ ; $-2x=9$ ; $\dfrac{x}{3}=-4$ ; $0{,}5x=6$.
:::

:::exercice Équations du type $ax+b=c$
Résoudre : $3x+5=20$ ; $4x-7=-15$ ; $-5x+2=17$ ; $6-x=10$ ; $\dfrac{2}{3}x+1=5$.
:::

:::exercice Inconnue dans les deux membres
Résoudre : $5x-4=2x+8$ ; $3(x-2)=x+4$ ; $4x+1=7x-11$ ; $2(3x+1)-5=4x+7$.
:::

:::exercice Problème : âges
Le père de Karim a $28$ ans de plus que lui. La somme de leurs âges est $52$ ans. Quel est l’âge de chacun ?
:::

:::exercice Problème : périmètre
La longueur d’un rectangle dépasse sa largeur de $5$ cm et son périmètre est $46$ cm. Calculer ses dimensions.
:::

:::exercice Approfondissement — les tirelires
Amine a $3$ fois plus d’argent que Salma. Si Amine donne $40$ DH à Salma, ils ont la même somme. Combien chacun avait-il au départ ?
:::

:::exercice Approfondissement — équation avec fractions
Résoudre : $\dfrac{x}{2}+\dfrac{x}{3}+\dfrac{x}{6}=12$, puis $\dfrac{2x-1}{3}=\dfrac{x+4}{2}$.
:::

# Corrigés

:::corrige
1. $4\times3-5=7$ : oui. $2\times3+1=7$ et $3+3=6$ : non.
2. $(-2)^2=4$ : oui. $3\times(-2)+8=2$ et $-2+4=2$ : oui.
:::

:::corrige
$x=-5$ ; $x=4$ ; $x=-5$ ; $x=-\dfrac92$ ; $x=-12$ ; $x=12$.
:::

:::corrige
- $3x=15$ : $x=5$.
- $4x=-8$ : $x=-2$.
- $-5x=15$ : $x=-3$.
- $-x=4$ : $x=-4$.
- $\dfrac23x=4$ : $x=4\times\dfrac32=6$.
:::

:::corrige
- $3x=12$ : $x=4$.
- $3x-6=x+4\iff2x=10\iff x=5$.
- $-3x=-12$ : $x=4$.
- $6x+2-5=4x+7\iff2x=10\iff x=5$.
:::

:::corrige
Soit $x$ l’âge de Karim : $x+(x+28)=52\iff2x=24\iff x=12$. Karim a $12$ ans et son père $40$ ans.
:::

:::corrige
Soit $\ell$ la largeur : $2(\ell+\ell+5)=46\iff4\ell+10=46\iff\ell=9$. Largeur $9$ cm, longueur $14$ cm (vérification : $2\times23=46$).
:::

:::corrige
Soit $x$ la somme de Salma ; Amine a $3x$. $3x-40=x+40\iff2x=80\iff x=40$. Salma avait $40$ DH et Amine $120$ DH (ensuite $80$ DH chacun).
:::

:::corrige
- On multiplie par $6$ : $3x+2x+x=72\iff6x=72\iff x=12$.
- On multiplie par $6$ : $2(2x-1)=3(x+4)\iff4x-2=3x+12\iff x=14$.
:::
