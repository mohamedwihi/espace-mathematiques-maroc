## Objectifs
- Connaître les nombres décimaux relatifs, leur signe et leur distance à zéro.
- Repérer un point sur une droite graduée et dans un repère du plan.
- Reconnaître deux nombres opposés.
- Comparer et ranger des nombres décimaux relatifs.

## Prérequis
- Nombres décimaux ; comparaison des décimaux.
- Droite graduée.

# I. Nombres décimaux relatifs

:::exemple Les températures
Un matin d’hiver, on relève : Ifrane $-4\,°$C, Rabat $+12\,°$C, Midelt $-1{,}5\,°$C, Agadir $+18\,°$C. Les températures inférieures à $0\,°$C sont notées avec le signe $-$.
:::

:::definition
- Un nombre écrit avec le signe $+$ (ou sans signe) est un nombre **positif** : $+3$, $12$, $+0{,}5$.
- Un nombre écrit avec le signe $-$ est un nombre **négatif** : $-4$, $-1{,}5$.
- Les nombres positifs et négatifs forment les **nombres décimaux relatifs**.
- La **distance à zéro** d’un nombre relatif est le nombre sans son signe.
:::

:::exemple
La distance à zéro de $-7{,}2$ est $7{,}2$ ; celle de $+5$ est $5$.
:::

:::remarque
$0$ est à la fois positif et négatif ; c’est le seul nombre dans ce cas.
:::

# II. Droite graduée et abscisse

:::definition
Une **droite graduée** est une droite munie d’une origine $O$, d’un sens et d’une unité. Tout point $M$ de cette droite est repéré par un nombre relatif appelé **abscisse** de $M$ ; on note $M(x)$.
:::

```figure
 "caption":"$A$ et $D$ sont symétriques par rapport à $O$ : leurs abscisses sont opposées."}
```

:::definition Nombres opposés
Deux nombres relatifs sont **opposés** s’ils ont la même distance à zéro et des signes contraires. Sur une droite graduée, les points d’abscisses opposées sont symétriques par rapport à l’origine.
:::

:::exemple
$-4$ et $4$ sont opposés ; l’opposé de $-2{,}7$ est $2{,}7$ ; l’opposé de $0$ est $0$.
:::

# III. Repérage dans le plan

:::definition
Un **repère** du plan est formé de deux droites graduées perpendiculaires de même origine $O$ : l’axe des **abscisses** (horizontal) et l’axe des **ordonnées** (vertical). Tout point $M$ est repéré par un couple de nombres relatifs $(x;y)$ : ses **coordonnées**.
:::

```figure

 "points":[{"x":3,"y":2,"label":"A(3;2)"},{"x":-2,"y":3,"label":"B(-2;3)"},{"x":-3,"y":-2,"label":"C(-3;-2)"},{"x":2,"y":-3,"label":"D(2;-3)"}],
 "segments":[{"from":[3,0],"to":[3,2],"dashed":true},{"from":[0,2],"to":[3,2],"dashed":true}],
 "caption":"L’abscisse se lit sur l’axe horizontal, l’ordonnée sur l’axe vertical."}
```

:::remarque
Un point de l’axe des abscisses a une ordonnée nulle ; un point de l’axe des ordonnées a une abscisse nulle. L’origine est $O(0;0)$.
:::

# IV. Comparaison des nombres relatifs

:::regle
- Un nombre négatif est **inférieur** à un nombre positif : $-3<2$.
- Deux nombres **positifs** sont rangés dans l’ordre de leurs distances à zéro : $2{,}5<4$.
- Deux nombres **négatifs** sont rangés dans l’ordre **inverse** de leurs distances à zéro : $-5<-2$ car $5>2$.
:::

:::remarque
Sur une droite graduée orientée de gauche à droite, le plus petit de deux nombres est l’abscisse du point situé le plus à gauche.
:::

:::exemple
- $-7{,}1<-6{,}9$ car $7{,}1>6{,}9$.
- Rangement croissant de $3$ ; $-2$ ; $0$ ; $-4{,}5$ ; $1{,}2$ : $-4{,}5<-2<0<1{,}2<3$.
:::

# Exercices

:::exercice Signe et distance à zéro
Parmi les nombres $-3{,}2$ ; $7$ ; $0$ ; $-11$ ; $+0{,}4$ ; $-0{,}06$, donner :
1. les nombres positifs, puis les nombres négatifs ;
2. la distance à zéro de chacun ;
3. l’opposé de chacun.
:::

:::exercice Droite graduée
1. Tracer une droite graduée d’unité $1$ cm et placer : $A(-3)$, $B(2{,}5)$, $C(-1)$, $D(4)$, $E(-4{,}5)$.
2. Quelles sont les distances $OA$, $OB$ et $OE$ ?
3. Placer le point $F$ symétrique de $B$ par rapport à $O$ ; donner son abscisse.
:::

:::exercice Repère
Dans un repère orthonormé, placer $A(2;3)$, $B(-3;1)$, $C(-2;-3)$, $D(0;-2)$ et $E(4;0)$.
1. Quels points sont sur un axe ?
2. Donner les coordonnées du symétrique de $A$ par rapport à $O$.
:::

:::exercice Comparaison
1. Compléter par $<$ ou $>$ : $-8\ldots3$ ; $-2{,}5\ldots-2{,}05$ ; $-0{,}1\ldots-1$ ; $0\ldots-6$.
2. Ranger par ordre croissant : $-1{,}5$ ; $2$ ; $-3$ ; $0{,}5$ ; $-0{,}75$ ; $1{,}25$.
3. Ranger par ordre décroissant : $-12$ ; $9{,}5$ ; $-12{,}5$ ; $0$ ; $-9$.
:::

:::exercice Températures
On relève les températures suivantes à six heures du matin : Ifrane $-6\,°$C, Fès $3\,°$C, Azilal $-2{,}5\,°$C, Oujda $1\,°$C, Midelt $-4\,°$C.
1. Quelles villes ont une température négative ?
2. Ranger ces températures de la plus froide à la plus chaude.
:::

# Corrigés

:::corrige
1. Positifs : $7$, $0$, $+0{,}4$ ; négatifs : $-3{,}2$, $0$, $-11$, $-0{,}06$ ($0$ est les deux).
2. Distances à zéro : $3{,}2$ ; $7$ ; $0$ ; $11$ ; $0{,}4$ ; $0{,}06$.
3. Opposés : $3{,}2$ ; $-7$ ; $0$ ; $11$ ; $-0{,}4$ ; $0{,}06$.
:::

:::corrige
2. $OA=3$ cm, $OB=2{,}5$ cm, $OE=4{,}5$ cm (distances à zéro des abscisses).
3. $F(-2{,}5)$.
:::

:::corrige
1. $D(0;-2)$ est sur l’axe des ordonnées et $E(4;0)$ sur l’axe des abscisses.
2. Le symétrique de $A$ par rapport à $O$ est $A'(-2;-3)$.
:::

:::corrige
1. $-8<3$ ; $-2{,}5<-2{,}05$ ; $-0{,}1>-1$ ; $0>-6$.
2. $-3<-1{,}5<-0{,}75<0{,}5<1{,}25<2$.
3. $9{,}5>0>-9>-12>-12{,}5$.
:::

:::corrige
1. Ifrane, Azilal et Midelt.
2. $-6<-4<-2{,}5<1<3$ : Ifrane, Midelt, Azilal, Oujda, Fès.
:::
