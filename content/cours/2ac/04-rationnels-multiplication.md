## Objectifs
- Multiplier deux ou plusieurs nombres rationnels et déterminer le signe du produit.
- Connaître l’inverse d’un rationnel non nul.
- Diviser deux nombres rationnels ; calculer avec des fractions d’étages.

## Prérequis
- Nombres rationnels : signe, simplification.
- Multiplication des nombres relatifs.

# I. Produit de deux rationnels

:::regle
Pour multiplier deux rationnels, on multiplie les numérateurs entre eux et les dénominateurs entre eux :
$$\frac ab\times\frac cd=\frac{a\times c}{b\times d}\qquad(b\ne0,\ d\ne0).$$
:::

:::remarque
Le signe du produit suit la règle des signes : même signe, produit positif ; signes contraires, produit négatif. En particulier $k\times\dfrac ab=\dfrac{k\times a}{b}$.
:::

:::exemple
- $\dfrac{-3}{5}\times\dfrac{2}{7}=\dfrac{-6}{35}$.
- $\dfrac{-4}{9}\times\dfrac{-3}{8}=\dfrac{4\times3}{9\times8}=\dfrac{4\times3}{3\times3\times4\times2}=\dfrac16$.
- $-6\times\dfrac{5}{4}=\dfrac{-30}{4}=\dfrac{-15}{2}$.
:::

:::methode Simplifier avant de multiplier
On décompose numérateurs et dénominateurs en produits, on simplifie les facteurs communs, puis on multiplie :
$$\frac{15}{-14}\times\frac{21}{10}=-\frac{3\times5\times3\times7}{2\times7\times2\times5}=-\frac94.$$
:::

# II. Produit de plusieurs rationnels

:::propriete
- La multiplication est **commutative** et **associative**.
- Le produit de rationnels non nuls est **positif** si le nombre de facteurs négatifs est pair, **négatif** s’il est impair.
- Un produit est nul si l’un de ses facteurs est nul.
:::

:::exemple
$\dfrac{-2}{3}\times\dfrac{9}{-4}\times\dfrac{-5}{6}$ : trois facteurs négatifs, le produit est négatif :
$$-\frac{2\times9\times5}{3\times4\times6}=-\frac{90}{72}=-\frac54.$$
:::

# III. Inverse d’un rationnel

:::definition
Deux nombres sont **inverses** l’un de l’autre si leur produit est égal à $1$.

L’inverse du rationnel non nul $\dfrac ab$ ($a\ne0$, $b\ne0$) est $\dfrac ba$ ; l’inverse d’un nombre $x\ne0$ se note $\dfrac1x$.
:::

:::exemple
- L’inverse de $\dfrac{3}{7}$ est $\dfrac{7}{3}$ ; l’inverse de $\dfrac{-2}{5}$ est $\dfrac{5}{-2}=-\dfrac52$.
- L’inverse de $4$ est $\dfrac14$ ; l’inverse de $-0{,}5$ est $-2$.
:::

:::remarque
- $0$ n’a pas d’inverse.
- Un nombre et son inverse ont le **même signe** (ne pas confondre avec l’opposé).
:::

# IV. Quotient de deux rationnels

:::regle
Diviser par un nombre non nul revient à **multiplier par son inverse** :
$$\frac ab\div\frac cd=\frac ab\times\frac dc\qquad(b\ne0,\ c\ne0,\ d\ne0).$$
:::

:::exemple
- $\dfrac{3}{4}\div\dfrac{9}{8}=\dfrac34\times\dfrac89=\dfrac{24}{36}=\dfrac23$.
- $\dfrac{-5}{6}\div10=\dfrac{-5}{6}\times\dfrac1{10}=-\dfrac1{12}$.
:::

:::methode Fraction d’étages
$$\frac{\dfrac ab}{\dfrac cd}=\frac ab\times\frac dc\qquad\text{par exemple}\qquad\frac{\dfrac{2}{3}}{\dfrac{-4}{9}}=\frac23\times\frac{9}{-4}=-\frac{18}{12}=-\frac32.$$
:::

# Exercices

:::exercice Produits
Calculer et donner le résultat sous forme irréductible : $\dfrac{-2}{3}\times\dfrac{5}{7}$ ; $\dfrac{-6}{25}\times\dfrac{-10}{9}$ ; $\dfrac{14}{-15}\times\dfrac{5}{21}$ ; $-8\times\dfrac{-3}{20}$.
:::

:::exercice Plusieurs facteurs
Déterminer le signe, puis calculer : $A=\dfrac{-3}{4}\times\dfrac{8}{-9}\times\dfrac{-6}{5}$ ; $B=\dfrac{-1}{2}\times\dfrac{-2}{3}\times\dfrac{-3}{4}\times\dfrac{-4}{5}$.
:::

:::exercice Inverses
1. Donner l’inverse de : $\dfrac{-5}{8}$ ; $7$ ; $-\dfrac{1}{3}$ ; $0{,}2$ ; $-1$.
2. Donner l’opposé et l’inverse de $\dfrac{4}{-9}$.
:::

:::exercice Quotients
Calculer : $\dfrac{-7}{12}\div\dfrac{14}{3}$ ; $\dfrac{5}{6}\div\dfrac{-10}{9}$ ; $-4\div\dfrac{2}{5}$ ; $\dfrac{\dfrac{3}{-8}}{\dfrac{9}{16}}$.
:::

:::exercice Problème
Hassan a dépensé les $\dfrac{2}{5}$ de son salaire pour le loyer, puis les $\dfrac{3}{4}$ du reste pour la nourriture.
1. Quelle fraction du salaire représente la nourriture ?
2. Son salaire est de $6\,000$ DH. Combien lui reste-t-il ?
:::

# Corrigés

:::corrige
$\dfrac{-10}{21}$ ; $\dfrac{60}{225}=\dfrac4{15}$ ; $-\dfrac{14\times5}{15\times21}=-\dfrac29$ ; $\dfrac{24}{20}=\dfrac65$.
:::

:::corrige
- $A$ : trois facteurs négatifs, signe $-$ : $A=-\dfrac{3\times8\times6}{4\times9\times5}=-\dfrac{144}{180}=-\dfrac45$.
- $B$ : quatre facteurs négatifs, signe $+$ : $B=\dfrac{1\times2\times3\times4}{2\times3\times4\times5}=\dfrac15$.
:::

:::corrige
1. $\dfrac{8}{-5}=-\dfrac85$ ; $\dfrac17$ ; $-3$ ; $5$ ; $-1$.
2. Opposé : $\dfrac49$ ; inverse : $-\dfrac94$.
:::

:::corrige
- $\dfrac{-7}{12}\times\dfrac3{14}=-\dfrac18$.
- $\dfrac56\times\dfrac9{-10}=-\dfrac34$.
- $-4\times\dfrac52=-10$.
- $\dfrac3{-8}\times\dfrac{16}9=-\dfrac23$.
:::

:::corrige
1. Reste après le loyer : $1-\dfrac25=\dfrac35$ ; nourriture : $\dfrac34\times\dfrac35=\dfrac9{20}$.
2. Dépenses : $\dfrac25+\dfrac9{20}=\dfrac{17}{20}$ ; reste $\dfrac3{20}\times6\,000=900$ DH.
:::
