## Objectifs
- Consolider les règles de calcul sur les nombres décimaux relatifs : somme, différence, produit, quotient.
- Calculer une somme algébrique et supprimer des parenthèses.
- Comparer des nombres relatifs et calculer une distance sur une droite graduée.

## Prérequis
- Nombres décimaux relatifs (1re année) : signe, distance à zéro, opposé, repérage.

# I. Rappels

:::definition
Tout nombre décimal relatif $a$ a un **signe** ($+$ ou $-$) et une **distance à zéro**. Deux nombres sont **opposés** s’ils ont la même distance à zéro et des signes contraires ; l’opposé de $a$ se note $-a$.
:::

:::regle Comparaison
- Un nombre négatif est inférieur à un nombre positif.
- Deux positifs sont rangés comme leurs distances à zéro ; deux négatifs dans l’ordre **inverse** de leurs distances à zéro.
:::

:::exemple
$-3{,}7<-3{,}07<0<0{,}3<3$.
:::

# II. Addition et soustraction

:::regle Somme
- **Même signe** : on garde le signe commun et on additionne les distances à zéro.
- **Signes contraires** : on prend le signe du nombre qui a la plus grande distance à zéro et on soustrait les distances à zéro.
:::

:::regle Différence
Soustraire un nombre, c’est ajouter son opposé : $a-b=a+(-b)$.
:::

:::exemple
$(-7)+(-5)=-12$ ; $(-7)+5=-2$ ; $(-4)-(-9)=-4+9=5$ ; $2{,}5-8=-5{,}5$.
:::

:::regle Suppression des parenthèses
- Précédée de $+$ : on supprime la parenthèse sans changer les signes.
- Précédée de $-$ : on supprime la parenthèse en changeant tous les signes à l’intérieur.
:::

:::exemple
$A=7-(3-10)+(-2+4)=7-3+10-2+4=21-5=16$.
:::

:::methode Distance sur une droite graduée
Si $A$ et $B$ ont pour abscisses $a$ et $b$, alors $AB=b-a$ si $b\ge a$, et $AB=a-b$ sinon.
Par exemple, pour $A(-3{,}5)$ et $B(2)$ : $AB=2-(-3{,}5)=5{,}5$.
:::

# III. Multiplication et division

:::regle
Pour multiplier ou diviser deux nombres relatifs, on multiplie ou on divise leurs distances à zéro ; le résultat est **positif** si les deux nombres ont le même signe, **négatif** sinon.
:::

:::regle Produit de plusieurs facteurs
Un produit de facteurs non nuls est positif si le nombre de facteurs négatifs est **pair**, négatif s’il est **impair**.
:::

:::exemple
$(-6)\times(-0{,}5)=3$ ; $\dfrac{-24}{8}=-3$ ; $(-1)\times(-2)\times(-5)\times4=-40$.
:::

# IV. Priorités opératoires

:::regle
On effectue d’abord les calculs entre parenthèses, puis les multiplications et divisions, puis les additions et soustractions (de gauche à droite).
:::

:::exemple
$$B=-3\times(4-9)+12\div(-4)=-3\times(-5)+(-3)=15-3=12.$$
:::

# Exercices

:::exercice Calculs
Calculer : $(-8)+(+3)$ ; $(-2{,}7)+(-4{,}3)$ ; $5-(-6)$ ; $-9-11$ ; $(-12)\times(-0{,}25)$ ; $\dfrac{-4{,}8}{-1{,}2}$ ; $(-7)\times3\times(-2)\times(-1)$.
:::

:::exercice Sommes algébriques
Calculer : $A=-15+8-6+20-3$ ; $B=4-(7-12)-(3+5)$ ; $C=-(2{,}5-6)+(1{,}5-4)$.
:::

:::exercice Priorités
Calculer : $D=6-4\times(-3)$ ; $E=(-5+2)\times(-4)-7$ ; $F=\dfrac{-18+6}{3}-2\times(-1{,}5)$ ; $G=-2\times\left[3-(5-9)\right]$.
:::

:::exercice Comparer et calculer
1. Ranger dans l’ordre croissant : $-2{,}1$ ; $1{,}9$ ; $-2{,}01$ ; $0$ ; $-1{,}99$.
2. Sur une droite graduée, $A(-4{,}5)$, $B(3)$ et $C(-1)$. Calculer $AB$, $AC$ et $BC$, et l’abscisse du milieu de $[AB]$.
:::

:::exercice Expression littérale
Calculer $x^2-3x+2$ et $(x-1)(x-2)$ pour $x=-2$, puis pour $x=0{,}5$. Que remarque-t-on ?
:::

:::exercice Approfondissement — somme alternée
Calculer astucieusement :
1. $S=1-2+3-4+5-6+\cdots+99-100$ ;
2. $T=(-1)+(+2)+(-3)+(+4)+\cdots+(-49)+(+50)$.
:::

:::exercice Approfondissement — expression à plusieurs lettres
On donne $a=-2$, $b=3$ et $c=-0{,}5$. Calculer :
$E=a-b\times c$ ; $F=(a-b)\times c$ ; $G=\dfrac{a\times b}{c}-a^2$ ; $H=-a-(b-c)\times a$.
:::

# Corrigés

:::corrige
$-5$ ; $-7$ ; $11$ ; $-20$ ; $3$ ; $4$ ; $-42$.
:::

:::corrige
- $A=(8+20)-(15+6+3)=28-24=4$.
- $B=4-7+12-3-5=1$.
- $C=-2{,}5+6+1{,}5-4=1$.
:::

:::corrige
- $D=6+12=18$.
- $E=(-3)\times(-4)-7=12-7=5$.
- $F=\dfrac{-12}3+3=-4+3=-1$.
- $G=-2\times(3+4)=-14$.
:::

:::corrige
1. $-2{,}1<-2{,}01<-1{,}99<0<1{,}9$.
2. $AB=3-(-4{,}5)=7{,}5$ ; $AC=-1-(-4{,}5)=3{,}5$ ; $BC=3-(-1)=4$. Milieu : $\dfrac{-4{,}5+3}2=-0{,}75$.
:::

:::corrige
- Pour $x=-2$ : $4+6+2=12$ et $(-3)\times(-4)=12$.
- Pour $x=0{,}5$ : $0{,}25-1{,}5+2=0{,}75$ et $(-0{,}5)\times(-1{,}5)=0{,}75$.

Les deux expressions donnent les mêmes valeurs : elles sont égales (on le démontrera par développement).
:::

:::corrige
1. On groupe par deux : $(1-2)+(3-4)+\cdots+(99-100)$ : $50$ groupes valant $-1$, donc $S=-50$.
2. $(-1+2)+(-3+4)+\cdots+(-49+50)$ : $25$ groupes valant $1$, donc $T=25$.
:::

:::corrige
- $E=-2-3\times(-0{,}5)=-2+1{,}5=-0{,}5$.
- $F=(-5)\times(-0{,}5)=2{,}5$.
- $G=\dfrac{-6}{-0{,}5}-4=12-4=8$.
- $H=2-(3{,}5)\times(-2)=2+7=9$.
:::
