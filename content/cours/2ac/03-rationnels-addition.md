## Objectifs
- Additionner et soustraire deux nombres rationnels de même dénominateur ou de dénominateurs différents.
- Utiliser l’opposé d’un rationnel.
- Calculer une somme algébrique de rationnels.

## Prérequis
- Nombres rationnels : signe, égalité, réduction au même dénominateur.
- Somme de nombres relatifs.

# I. Somme de deux rationnels

:::regle Même dénominateur
$$\frac ac+\frac bc=\frac{a+b}c\qquad\frac ac-\frac bc=\frac{a-b}c\qquad(c\ne0).$$
:::

:::exemple
$\dfrac{-5}{7}+\dfrac{3}{7}=\dfrac{-2}{7}$ ; $\dfrac{4}{9}-\dfrac{13}{9}=\dfrac{-9}{9}=-1$.
:::

:::methode Dénominateurs différents
On réduit les deux rationnels au **même dénominateur**, puis on applique la règle précédente. On simplifie le résultat.
:::

:::exemple
- $\dfrac{3}{4}+\dfrac{-5}{6}=\dfrac{9}{12}+\dfrac{-10}{12}=\dfrac{-1}{12}$.
- $\dfrac{-2}{3}-\dfrac{1}{5}=\dfrac{-10}{15}-\dfrac{3}{15}=\dfrac{-13}{15}$.
- $2-\dfrac{7}{3}=\dfrac63-\dfrac73=-\dfrac13$.
:::

:::regle Cas général
$$\frac ab+\frac cd=\frac{ad+bc}{bd}\qquad\frac ab-\frac cd=\frac{ad-bc}{bd}\qquad(b\ne0,\ d\ne0).$$
:::

:::exemple
$\dfrac{5}{2}-\dfrac{4}{5}=\dfrac{5\times5-4\times2}{10}=\dfrac{25-8}{10}=\dfrac{17}{10}$.
:::

# II. Opposé d’un rationnel

:::definition
L’**opposé** du rationnel $\dfrac ab$ est $-\dfrac ab=\dfrac{-a}{b}$. La somme de deux rationnels opposés est nulle : $\dfrac ab+\dfrac{-a}{b}=0$.
:::

:::regle
Soustraire un rationnel, c’est **ajouter son opposé** :
$$\frac ab-\frac cd=\frac ab+\frac{-c}{d}.$$
:::

:::exemple
$\dfrac{1}{3}-\dfrac{-4}{3}=\dfrac13+\dfrac43=\dfrac53$.
:::

# III. Propriétés

:::propriete 1 Commutativité
$x+y=y+x$ pour tous rationnels $x$ et $y$.
:::

:::propriete 2 Associativité
$(x+y)+z=x+(y+z)$ : on peut regrouper les termes comme on veut.
:::

:::propriete 3 Élément neutre
$x+0=0+x=x$.
:::

:::methode Calcul astucieux
On regroupe les termes de même dénominateur :
$$\frac{2}{5}+\frac{-3}{7}+\frac{3}{5}+\frac{10}{7}=\left(\frac25+\frac35\right)+\left(\frac{-3}7+\frac{10}7\right)=1+1=2.$$
:::

# IV. Sommes algébriques

:::regle Suppression des parenthèses
- $x+(y-z)=x+y-z$ ;
- $x-(y-z)=x-y+z$.
:::

:::exemple
$$A=\frac12-\left(\frac13-\frac14\right)=\frac12-\frac13+\frac14=\frac{6-4+3}{12}=\frac5{12}.$$
:::

# Exercices

:::exercice Même dénominateur
Calculer et simplifier : $\dfrac{-7}{11}+\dfrac{2}{11}$ ; $\dfrac{5}{8}-\dfrac{-3}{8}$ ; $\dfrac{-4}{15}-\dfrac{11}{15}$ ; $\dfrac{1}{6}+\dfrac{-5}{6}+\dfrac{7}{6}$.
:::

:::exercice Dénominateurs différents
Calculer et donner le résultat sous forme irréductible : $\dfrac{2}{3}+\dfrac{-5}{12}$ ; $\dfrac{-3}{8}-\dfrac{5}{6}$ ; $\dfrac{7}{10}-\dfrac{-2}{15}$ ; $-3+\dfrac{4}{7}$ ; $\dfrac{-1}{4}-\dfrac{2}{9}$.
:::

:::exercice Calcul astucieux
Calculer en regroupant : $B=\dfrac{5}{9}+\dfrac{-3}{4}+\dfrac{4}{9}+\dfrac{7}{4}$ ; $C=-\dfrac{3}{10}+\dfrac{2}{3}-\dfrac{7}{10}+\dfrac{1}{3}$.
:::

:::exercice Parenthèses
Calculer : $D=\dfrac{3}{4}-\left(\dfrac{1}{2}-\dfrac{5}{8}\right)$ ; $E=\left(1-\dfrac{2}{5}\right)-\left(\dfrac{3}{10}+\dfrac{-1}{2}\right)$.
:::

:::exercice Problème
Un réservoir est plein aux $\dfrac{3}{4}$. Lundi, on en utilise $\dfrac{1}{3}$ de la capacité totale, puis mardi on ajoute $\dfrac{1}{6}$ de la capacité totale.
1. Quelle fraction du réservoir est remplie mardi soir ?
2. La capacité est $120$ L. Quel volume contient-il mardi soir ?
:::

:::exercice Approfondissement — décomposition
1. Vérifier que pour tout entier $n\ge1$ : $\dfrac{1}{n}-\dfrac{1}{n+1}=\dfrac{1}{n(n+1)}$.
2. En déduire $A=\dfrac{1}{6}+\dfrac{1}{12}+\dfrac{1}{20}+\dfrac{1}{30}+\dfrac{1}{42}$.
:::

:::exercice Approfondissement — trouver le nombre manquant
Déterminer le rationnel $x$ dans chaque cas : $\dfrac{3}{4}+x=\dfrac{1}{6}$ ; $x-\dfrac{2}{5}=-\dfrac{7}{10}$ ; $\dfrac{5}{8}-x=1$.
:::
