## Objectifs
- Réduire et ordonner une expression littérale.
- Développer avec la distributivité simple et double.
- Factoriser une expression à l’aide d’un facteur commun.
- Connaître et utiliser les identités remarquables.

## Prérequis
- Expressions littérales, distributivité simple (1re année).
- Calcul sur les rationnels et les puissances.

# I. Expressions littérales

:::definition
Une **expression littérale** est une expression contenant une ou plusieurs lettres qui désignent des nombres. Chaque terme est formé d’un **coefficient** (nombre) et d’une **partie littérale**.
:::

:::exemple
Dans $5x^2-3x+7$ : le terme $5x^2$ a pour coefficient $5$ et pour partie littérale $x^2$ ; $-3x$ a pour coefficient $-3$ ; $7$ est le terme constant.
:::

:::definition Réduire et ordonner
**Réduire** une expression, c’est regrouper les termes **semblables** (même partie littérale). **Ordonner**, c’est écrire les termes du plus grand au plus petit exposant.
:::

:::exemple
$A=3x-5+2x^2-7x+x^2+8=3x^2-4x+3$ ;
$B=4ab-2a+ab+5a=5ab+3a$.
:::

:::methode Calculer une valeur
Pour $x=-2$ : $A=3\times(-2)^2-4\times(-2)+3=12+8+3=23$.
:::

# II. Développement

:::definition
**Développer** un produit, c’est l’écrire sous forme d’une somme algébrique.
:::

:::propriete Distributivité simple
$$k(a+b)=ka+kb\qquad k(a-b)=ka-kb.$$
:::

:::propriete Double distributivité
$$(a+b)(c+d)=ac+ad+bc+bd.$$
:::

:::exemple
- $-3x(2x-5)=-6x^2+15x$.
- $(x+3)(2x-1)=2x^2-x+6x-3=2x^2+5x-3$.
- $(2a-1)(a-4)=2a^2-8a-a+4=2a^2-9a+4$.
:::

# III. Factorisation

:::definition
**Factoriser** une somme, c’est l’écrire sous forme d’un **produit**.
:::

:::propriete
$$ka+kb=k(a+b)\qquad ka-kb=k(a-b).$$
:::

:::exemple
- $6x^2-9x=3x(2x-3)$.
- $5(x+1)+x(x+1)=(x+1)(5+x)$.
- $(2x-3)(x+4)-(2x-3)(3x-1)=(2x-3)\left[(x+4)-(3x-1)\right]=(2x-3)(-2x+5)$.
:::

# IV. Identités remarquables

:::propriete
Pour tous nombres $a$ et $b$ :
$$(a+b)^2=a^2+2ab+b^2$$
$$(a-b)^2=a^2-2ab+b^2$$
$$(a+b)(a-b)=a^2-b^2$$
:::

:::demonstration
$(a+b)^2=(a+b)(a+b)=a^2+ab+ba+b^2=a^2+2ab+b^2$. Les deux autres se démontrent de la même façon.
:::

:::exemple Développer
- $(x+5)^2=x^2+10x+25$.
- $(3a-2)^2=9a^2-12a+4$.
- $(2x+7)(2x-7)=4x^2-49$.
:::

:::exemple Factoriser
- $x^2+6x+9=(x+3)^2$.
- $4y^2-20y+25=(2y-5)^2$.
- $x^2-16=(x-4)(x+4)$ ; $9a^2-1=(3a-1)(3a+1)$.
:::

:::exemple Calcul mental
$101^2=(100+1)^2=10\,000+200+1=10\,201$ ; $49\times51=(50-1)(50+1)=2\,500-1=2\,499$.
:::

# Exercices

:::exercice Réduire
Réduire et ordonner : $A=5x-3+x^2-8x+4-3x^2$ ; $B=2(a^2-a)+3a-a^2$ ; $C=xy-3x+4xy+x$.
:::

:::exercice Développer
Développer et réduire : $D=-2x(3x-4)$ ; $E=(x-2)(x+6)$ ; $F=(3a+1)(2a-5)$ ; $G=(x+1)(x-1)-x(x-2)$.
:::

:::exercice Identités remarquables
Développer : $(x+4)^2$ ; $(2a-3)^2$ ; $(5y+1)(5y-1)$ ; $\left(x-\dfrac12\right)^2$.
:::

:::exercice Factoriser
Factoriser : $8x^2+12x$ ; $(x-3)(2x+1)+(x-3)(x+5)$ ; $x^2-10x+25$ ; $49-a^2$ ; $4x^2+4x+1$ ; $(x+2)^2-9$.
:::

:::exercice Calcul astucieux
Calculer sans calculatrice : $99^2$ ; $1\,002^2$ ; $103\times97$ ; $2\,026^2-2\,025^2$.
:::

:::exercice Aire
Un carré a pour côté $x+3$. On enlève dans un coin un carré de côté $3$.
1. Exprimer l’aire de la partie restante en fonction de $x$.
2. Montrer que cette aire est égale à $x(x+6)$.
:::

# Corrigés

:::corrige
$A=-2x^2-3x+1$ ; $B=a^2+a$ ; $C=5xy-2x$.
:::

:::corrige
- $D=-6x^2+8x$.
- $E=x^2+6x-2x-12=x^2+4x-12$.
- $F=6a^2-15a+2a-5=6a^2-13a-5$.
- $G=x^2-1-x^2+2x=2x-1$.
:::

:::corrige
$x^2+8x+16$ ; $4a^2-12a+9$ ; $25y^2-1$ ; $x^2-x+\dfrac14$.
:::

:::corrige
- $4x(2x+3)$.
- $(x-3)\left[(2x+1)+(x+5)\right]=(x-3)(3x+6)=3(x-3)(x+2)$.
- $(x-5)^2$ ; $(7-a)(7+a)$ ; $(2x+1)^2$.
- $(x+2-3)(x+2+3)=(x-1)(x+5)$.
:::

:::corrige
- $(100-1)^2=10\,000-200+1=9\,801$.
- $(1\,000+2)^2=1\,000\,000+4\,000+4=1\,004\,004$.
- $(100+3)(100-3)=10\,000-9=9\,991$.
- $(2\,026-2\,025)(2\,026+2\,025)=4\,051$.
:::
